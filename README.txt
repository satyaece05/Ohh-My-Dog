OHH MY DOG WEBSITE
===================

Open index.html in a browser to preview the website.

The site is a single responsive HTML file and needs no server to preview.

Included:
- Home / hero section
- Services
- Products catalogue
- Dog & cat food brands
- About section
- Contact information
- Click-to-call
- WhatsApp enquiry buttons
- Google Maps directions link
- Mobile navigation

Suggested next improvements:
1. Add the shop logo.
2. Add real photos of the shop, dogs/cats and products.
3. Add individual product cards with pack size and price.
4. Add a real online order/cart system if required.
5. Publish using a domain and hosting provider.
